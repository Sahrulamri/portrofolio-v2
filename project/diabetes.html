Klasifikasi Prediksi Risiko Diabetes - Detail Proyek

Role

Data Analyst

Tech Stack

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn (Logistic Regression, K-Nearest Neighbors, Random Forest, StandardScaler, RobustScaler, GridSearchCV, train_test_split), XGBoost, LightGBM

Fitur Utama

Pra-pemrosesan Data Medis (Medical Zero-Imputation), Engineering Fitur Klinis (Clinical Feature Engineering, Penskalaan Data Lanjutan, Pemodelan Multi-Algoritma & Ensemble, Evaluasi Performa Komprehensif

📝

Project Description

Proyek ini membangun sistem klasifikasi medis berbasis machine learning end-to-end untuk mendeteksi dini risiko penyakit diabetes pada pasien. Dimulai dari pembersihan data klinis, rekayasa fitur berbasis domain kesehatan (feature engineering), optimasi hyperparameter, hingga implementasi model ensemble modern (XGBoost dan LightGBM), proyek ini berhasil mencapai akurasi optimal sebesar 78.45% dengan peningkatan performa signifikan pada deteksi kelas minoritas.

📜

Background

  • Diabetes melitus adalah salah satu penyakit kronis paling berbahaya di dunia yang memerlukan deteksi dini untuk mencegah komplikasi fatal bagi pasien.
  • Data klinis mentah sering kali mengandung anomali (seperti nilai nol pada parameter biologis yang secara medis tidak mungkin terjadi) serta distribusi data yang kompleks.
  • Oleh karena itu, dibutuhkan sistem kecerdasan buatan berbasis machine learning yang mampu memproses data kesehatan secara akurat guna membantu tenaga medis dalam mendiagnosis risiko diabetes secara cepat dan proaktif.
🎯

Objective

  • Membangun model prediktif klasifikasi risiko diabetes yang handal dan akurat menggunakan data klinis pasien[cite: 30, 35].
  • Menerapkan teknik data imputation dan advanced feature engineering untuk mengekstrak pola klinis yang lebih kuat dari dataset[cite: 31, 35].
  • Membandingkan performa berbagai algoritma klasifikasi serta mengoptimalkan model menggunakan pendekatan Ensemble Learning (XGBoost & LightGBM)[cite: 31, 35].
📊

Dataset

  • Sumber Data: Dataset Pima Indians Diabetes dari platform Kaggle[cite: 30].
  • Struktur & Ukuran Dataset: Terdiri dari 768 baris sampel pasien dan 9 kolom (8 kolom fitur prediktor klinis dan 1 kolom target)[cite: 30].
  • Atribut / Kolom Utama:
    • Pregnancies (preg): Jumlah riwayat kehamilan pasien[cite: 30].
    • Glucose (plas): Konsentrasi glukosa plasma 2 jam dalam tes toleransi glukosa oral[cite: 30].
    • BloodPressure (pres): Tekanan darah diastolik dalam satuan milimeter merkuri (mm Hg)[cite: 30].
    • SkinThickness (kulit): Ketebalan lipatan kulit trisep dalam satuan milimeter (mm)[cite: 30].
    • Insulin (Tes): Kadar insulin serum 2 jam dalam satuan $\mu\text{U/ml}$[cite: 30].
    • BMI (Massa): Indeks Massa Tubuh, dihitung dari berat badan $(\text{kg})$ dibagi kuadrat tinggi badan $(\text{m}^2)$[cite: 30].
    • DiabetesPedigreeFunction (pedi): Fungsi silsilah diabetes yang merepresentasikan skor riwayat genetik keluarga[cite: 30].
    • Age (usia): Usia pasien dalam satuan tahun[cite: 30].
    • Outcome (Kelas): Variabel target (1 = Positif Diabetes, 0 = Negatif Diabetes)[cite: 30].
💡

What

Proyek ini merupakan sistem kecerdasan buatan berbasis Python yang mengotomatisasi alur kerja data sains (data science pipeline)—mulai dari pembersihan data klinis, rekayasa fitur berbasis domain kedokteran, normalisasi skala data, hingga pelatihan model ensemble—untuk mengklasifikasikan apakah seorang pasien mengidap diabetes atau tidak berdasarkan indikator biometrik mereka[cite: 30, 31, 35].

❓

Why

  • Deteksi Dini yang Presisi: Membantu mengidentifikasi pasien berisiko tinggi sebelum gejala klinis parah muncul.
  • Mengatasi Keterbatasan Data Mentah: Data kesehatan riil sering kali memiliki nilai kosong terselubung (nilai 0 pada variabel medis). Pendekatan imputasi median dan pembuatan fitur interaksi klinis terbukti mampu meningkatkan kemampuan generalisasi model secara signifikan[cite: 31, 35].
</>

How

  1. Pra-pemrosesan & Pembersihan Data: Mengganti nilai 0 yang tidak logis pada kolom medis (Glucose, BloodPressure, SkinThickness, Insulin, BMI) menjadi NaN, lalu mengisinya kembali menggunakan nilai median kolom tersebut[cite: 31].
  2. Feature Engineering: Menambahkan variabel interaksi klinis baru seperti rasio Glucose-BMI, indikator hipertensi (High_BP), status obesitas (Obese), dan ambang batas glukosa tinggi (High_Glucose)[cite: 35].
  3. Pemisahan & Penskalaan Data: Membagi dataset menjadi data latih dan data uji (dengan parameter stratify agar proporsi kelas seimbang), lalu menormalisasikannya menggunakan RobustScaler[cite: 31, 35].
  4. Pemodelan & Ensemble: Melatih model baseline (Logistic Regression, KNN, Random Forest), lalu menerapkan optimasi lanjutan menggunakan XGBoost dan LightGBM yang digabungkan melalui metode Soft Voting Ensemble[cite: 31, 33, 35].
📈

Results

  • Model Baseline: Model awal seperti Logistic Regression memperoleh akurasi sekitar 70.13%, KNN sebesar 75.32%, dan Random Forest mencapai 77.92%[cite: 32, 33].
  • Optimasi Random Forest: Penyesuaian class weight pada Random Forest menghasilkan akurasi stabil di angka 77.00% dengan peningkatan keseimbangan pada Recall kelas positif[cite: 34].
  • Model Ensemble Terbaik (XGBoost + LightGBM + Feature Engineering): Integrasi rekayasa fitur klinis lanjutan dan Soft Voting Ensemble berhasil mencatatkan performa puncak dengan Akurasi Akhir mencapai 78.45%, Precision kelas positif 0.67, dan Recall kelas positif 0.72[cite: 35].
🏁

Conclusion

  • Penanganan nilai nol yang tepat pada data medis serta penambahan fitur turunan (feature engineering) berbasis domain klinis terbukti sangat efektif dalam meningkatkan kualitas informasi yang diterima oleh model machine learning[cite: 31, 35].
  • Pendekatan Ensemble Learning yang menggabungkan kekuatan algoritma gradient boosting modern (XGBoost dan LightGBM) mampu memberikan performa prediktif yang lebih superior dan stabil dibandingkan model tunggal konvensional[cite: 35].
